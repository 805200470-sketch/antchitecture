# 蚂蚁花园 · Unity 版操作说明

## 在 Windows 电脑上演示

1. 把整个 `05_Builds.nosync/AntGarden_Windows` 文件夹拷到 U 盘或 T9，再复制到 Windows 电脑上。
2. 双击 `AntGarden.exe`。那台电脑不需要安装 Unity。游戏默认在 1280×720 的窗口里打开，按 `F` 切换全屏。
3. 如果出现"Windows 已保护你的电脑"：点"更多信息" → "仍要运行"。程序没有签名，所以会有这个提示。
4. 退出：`Alt + F4`（Mac 上是 `Cmd + Q`）。

Mac 版在 `05_Builds.nosync/AntGarden_Mac/AntGarden.app`，用来在这台电脑上测试。

## 操作

| 按键 | 作用 |
|---|---|
| `W` `A` `S` `D` / 方向键 | 爬行，方向以镜头为准（0.75 个身长/秒，和 NPC 走路差不多快；转弯是一段弧线，不会原地猛扭）。可以往两侧土坡上爬，快到坡顶时有一道看不见的墙挡住 |
| 按住 `Shift` | 快爬（只比爬行快一点：1.25 个身长/秒） |
| 鼠标左键拖动 | 转动镜头（松手后镜头留在你放的地方，1.4 秒后才在你往前跑时慢慢回到身后） |
| 鼠标滚轮 | 拉近 / 拉远 |
| `空格` | 停下时伸出触角点一点；触角碰到发光植物，它会亮起来 |
| `E` | 靠近蚂蚁时和它碰触角；在发光圆环旁边时查看故事物件位；在**传送光门**前穿过去，到另一个蚁穴；在出口旁边时前往下一个蚁穴 |
| `M` | 打开地图：点地图上任意位置就传送过去；下面一排按钮可以去洞室、物件位、光门、出口，最下面一排切换世界（第一个"蚁穴群岛"是默认世界） |
| `Tab` | 切换画质：低 → 中 → 高，切换后世界会重新生成 |
| `F` | 窗口 / 全屏切换 |
| `L` | 界面语言：中文 / English（会记住你的选择） |
| `H` | 隐藏 / 显示左上角的说明 |
| `Esc` | 关闭地图或物件位面板（不会退出游戏） |

## Xbox 手柄（2026-10-13）

插上手柄就能玩，键盘和鼠标照样能用，两种可以随时混着用。

| 手柄 | 作用 |
|---|---|
| 左摇杆（或十字键） | 爬行，方向以镜头为准；推得轻就走得慢 |
| 右摇杆 | 转镜头：左右绕着蚂蚁转，上下抬低视角 |
| RT（右扳机，或按下左摇杆） | 按住快爬 |
| A | 交互，等于键盘的 `E`：碰触角、和遗物说话、过传送光门 |
| B | 停下时伸出触角，等于 `空格`；打开地图或物件位面板时是返回/关闭 |
| Y | 打开 / 关闭地图。地图里用左摇杆移动光标，按 A 传送过去，按 B 关闭 |
| LB / RB | 镜头拉远 / 拉近 |
| ☰（菜单键） | 显示 / 隐藏说明 |

- 用手柄时，屏幕下方的提示会自动从"按 E"变成"按 A"。
- 碰触角、和遗物说话、碰亮发光植物、传送时，手柄会轻震一下。不想要的话，在 `game_config.json` 里写 `"padRumble": false`。
- 连接方式：
  - **Mac**：用蓝牙配对（长按手柄顶部的配对键，在"系统设置 → 蓝牙"里连接）。Mac 对 Xbox 手柄的有线连接支持不稳定。
  - **Windows**：USB 线或蓝牙都可以。
- 灵敏度在 `GameConfig.cs` 的 `camera.padTurnSpeed` 和 `camera.padPitchSpeed`。
- 用的是 Unity 新的输入系统（Input System 1.11.2），键盘和鼠标仍走原来的输入，两套并存。
- 检查工具 `-padcheck <文件夹>` 会接一个虚拟手柄，自动按一遍所有键，写成 `pad_report.json`，现在 12 项全部通过。

## 镜头（2026-10-13 重做）

像一般的第三人称游戏：
- 镜头像用绳子拖在蚂蚁身后。按 `D` 或 `A` 是绕着镜头画一个大圈；按 `S` 是朝镜头走过来，镜头往后退，不会再原地打转；松开按键，镜头就停住不动。
- 按住 `W` 往前跑时，镜头会慢慢转到蚂蚁身后。所以 `W` 加 `A` 或 `D` 就像开车转弯，转得不急。
- 在峡谷里，镜头碰到岩壁会贴着岩壁滑，保持原来的距离；只有蚂蚁真的被挡住时才拉近，拉近后停 0.35 秒再慢慢退回去，不会忽近忽远。
- 隧道里镜头贴着平滑的顶走，不跟着顶上的起伏上下跳。
- 快爬时视野只放宽一点（5°）。

参数在 `GameConfig.cs` 的 `camera`：`recenterRate`（回到身后的快慢）、`followDelay`（拖完镜头多久才开始回）、`slideRate`、`followSmooth`、`zoomHold`、`zoomOutRate`。

旧镜头的问题是一直往蚂蚁身后甩。按 `S` 时，蚂蚁和镜头会一起原地打转，每秒约 190°。

用 `-camcheck` 让程序模拟键盘玩一遍（`W` 加 `A`/`D` 沿峡谷走、快跑、只按 `D`、按 `S`、拖完镜头松手），新旧镜头对比如下：

| 测量 | 旧镜头 | 新镜头 |
|---|---|---|
| 快跑 14 秒内的突然晃动 | 36–45 次 | 0 次 |
| 只按 `D` 时镜头转动 | 每秒 115° | 每秒 14° |
| 按 `S` 时镜头转动 | 每秒 190° | 每秒 1° |
| 松手站定后镜头还在转 | 每秒 17° | 不转 |

## 土坡、碰撞和植物分布（2026-10-13 晚）

- **爬坡和空气墙**：
  - 你控制的蚂蚁可以离开谷底，顺着两侧土坡往上爬，身体随坡面倾斜。
  - 坡从峡谷边缘往外约 4.5 个单位升到坡顶。空气墙在离峡谷边缘 3.9 处，实测能爬到坡高的约 92%（爬升 4.6，坡高 5），不会翻过坡顶。
  - 遗迹隧道里顶会压下来，所以只能爬到 3.2 处。
  - NPC 仍然在谷底沿路线走。
  - 参数在 `GameConfig.cs` 的 `ant.climb` 和 `World.tunnelClimb`。
- **所有物件都有碰撞**：
  - 低矮宽平的东西会变成一个小土包，蚂蚁爬上去走过，脚和身体贴着表面，不会穿过去。包括小石子、落叶、苔藓垫、种子堆，以及遗迹里的钥匙（当成桥）、铜钱（台地）和纽扣（广场）。
  - 其余东西都是实心的，蚂蚁要绕开。以前有 7 种地面小物件可以直接穿过去，现在没有了。
  - 蚂蚁对植物的碰撞圈比对岩壁小一点（身体细长），可以从茎秆之间钻过去。
  - 参数在 `scatter.stepUp`、`scatter.stepUpBroad`。
- **植物有聚有散**：
  - 每种植物按"这片土适不适合它"成片生长。适合程度一半来自所有植物共用的分布，所以几种植物会扎堆成小林子；另一半来自它自己，所以每片林子的组成不一样。
  - 空地上只剩零星几株，总量和以前差不多。
  - 参数是每条规则的 `patchiness`（0 = 均匀，1 = 只成片），大树和背景树林比较均匀。

## 蚂蚁的腿（2026-10-13）

- 默认改回**原版动画腿**（`ant.proceduralLegs = false`）：关节转动平滑很多，测下来每秒约 600°，没有突跳，姿态和模型原本的动画一致。代价是脚会在地上轻微滑动。
- 程序腿（每一步把脚踩实）仍然保留，加 `-proclegs 1` 或把 `proceduralLegs` 改成 `true` 就能切回去。它这次也修过：
  - 原来转向时步频会冲到每秒 7 到 8 步，有时一次抬腿只有一两帧，这就是"抽搐"。现在转向时最多每秒 3 步，节奏变化做了平滑。
  - 站着时不再原地踏步。
  - 脚落在比髋部高的地方时，膝盖不会再翻折。
- 对比视频：`Docs/演示视频/腿_对比_程序腿vs原版.mp4`。
- 检查工具 `-legcheck <文件夹> [-legdt 60|30|jitter]`：模拟以下几种情况，逐帧量步频、最短抬腿、关节转速、脚的抖动和打滑，写成 `leg_report.json`。
  - 直走、点按转向、快跑转向、走走停停、原地掉头、顶墙、站立、爬坡。
  - `jitter` 模拟帧率不稳的电脑。
  - 加 `-legframes 1` 会逐帧录近景。

  - 穿过蚁穴之间的光门、传送。
  - 打开和收起地图。
  - 环境声：野外是风和远处蟋蟀，隧道里是低沉气流和偶尔的滴水。

## 世界结构：蜂巢（默认，2026-10-13 起）

- **所有蚁穴拼成一整块蜂巢**：15 个六边形边贴边，没有空隙，也没有虚线传送门。
  - 中间是蓝色三穴（001、002、003）。
  - 紧挨着它们的是琥珀 010、遗迹 · 巨人遗物（003 的地下隧道）、遗迹 · 古蚁圣殿（010 的地下隧道）、蚁穴 004。
  - 外圈是另外 8 个蚁穴（005–009、011–013），蓝色和琥珀色交替。
- **怎么拼的**：
  - 每块六边形会自动转到合适的角度，让两边的峡谷出口尽量对上，再用一段 S 形峡谷穿过接缝连起来。
  - 接缝处有一道蓝绿色光门，走过去就进入下一个蚁穴，全程走路就能到，不用传送。
  - 实在对不上的边，会从最近的路分出一条岔路，或者在两边的路之间打通一段。
- **地面**：整块蜂巢只有一张连续的地面网格，所以接缝不会有裂缝。每格用自己的颜色（蓝色苔藓或琥珀干土），两种颜色沿六边形的边直线分开。
- **蚂蚁**：中间四格（001、002、003、010）各 100 只，其他格各 40 只。蚂蚁只在自己那一格的路上活动；离你远的格子会暂停，不占性能。
- **地图**：右上角小地图和 `M` 大地图都是整块蜂巢，点哪里都能传过去。外圈峡谷通到边缘的出口不再跳到别的世界，因为所有蚁穴都在这里了。
- **配置**：`GameConfig.defaultWorld` 写成 `honeycomb:path-001@blue,path-002@blue,…,path-003@blue#relics,…`，按顺序从中间往外排（第 1 个在中心，2–7 是第一圈，之后是第二圈），最多 19 格。拼接代码在 `Scripts/Core/Stitcher.cs`（`layout = "honeycomb"`）。

想换成别的组合，在 `game_config.json` 里写 `defaultWorld`。用 `|` 分开不相连的蚁穴，用 `@` 指定风格（`blue` 或 `amber`）：

```json
{ "defaultWorld": "stitch:cluster:path-001,path-002,path-003@blue|path-010@amber" }
```

（这是以前只有两个区域的版本。用 `#relics` / `#temple` 标出遗迹，每 4 个区域换一排。）

**修复记录（2026-10-13）**：
- 以前从地图下排按钮切换世界、走出口去下一个蚁穴、按 `Tab` 切画质，都会让画面卡在空场景。原因是重新加载场景后游戏主体没有重建，现在每次加载都会重建。
- 和蚂蚁交互时，以前会选中名单里第一只在范围内的蚂蚁，常常是身后或画面外那只。现在选你**正前方最近**的那只，选中后不会来回跳。
- 蚂蚁、物件位、出口离得都近时，以前总是先碰蚂蚁，现在**谁最近就和谁交互**。

单个蚁穴写 `path-013@amber` 即可。两种风格的颜色在 `GameConfig.cs` 的 `biomes` 里定义，可以照着再加新风格。

## 如果游戏越来越卡、甚至像卡死

2026-10-04 查过一次：当时游戏全屏、按 Retina 原生分辨率每秒画 120 帧，MacBook 又在用电池，4 分钟后系统报"过热"，帧率从 120 掉到 20 以下。之后合上了盖子，游戏在睡眠中一直挂着。现在已经改成：

- 默认小窗口，不再按 Retina 2 倍分辨率渲染。
- 每秒最多 60 帧；切到别的软件时自动降到 15 帧。
- 屏幕关闭或合盖时不会卡住画面循环。

演示时建议：插上电源，保持窗口模式（需要全屏再按 `F`），不玩时直接 `Cmd + Q` 退出，不要合着盖子开着游戏。帧率上限可以在 `game_config.json` 里改：

```json
{ "display": { "targetFps": 60, "backgroundFps": 15, "windowWidth": 1280, "windowHeight": 720 } }
```

## 画质

| 画质 | 说明 |
|---|---|
| 低 | 没有阴影，植物较稀，适合集成显卡 |
| 中（默认） | 有阴影，适合大多数独立显卡 |
| 高 | 地形更细，植物最密，有环境光遮蔽 |

左下角显示帧率。低于 30 帧就按 `Tab` 降一档。

## 调整数值（不用重新打包）

所有手感和画面数值都可以用一个文件覆盖：在 `AntGarden_Data/StreamingAssets/` 里新建 `game_config.json`，只写要改的项。例如让蚂蚁爬得快一点、雾淡一点：

```json
{
  "ant": { "crawlSpeed": 1.3, "fastSpeed": 3.0 },
  "atmosphere": { "fogDensity": 0.012 }
}
```

每一项的含义写在工程的 `Assets/AntGarden/Scripts/Runtime/GameConfig.cs` 里。

## 蚂蚁和蚁群

- 数量：高画质约 400 只（每个蚁穴 100 只），中画质约 65%，低画质约 30%。
- 种类：5 种蚂蚁都会出现，每种至少几只。会飞的 3 号蚂蚁很少（约 3%），而且不常起飞；其余都是地面蚂蚁。每个蚁穴以一种地面蚂蚁为主。
- 行为：大多数蚂蚁沿路径成列来回走（蚁路，到岔路口多半直行）；约四分之一聚在洞室里转悠、停下、碰触角，偶尔离开去走蚁路；少数在峡谷里四处游荡。两只蚂蚁迎面相遇会停下碰触角，再错开走。每个蚁穴以一种蚂蚁为主。
- 动画：镜头附近（约 18 米内）的蚂蚁用程序化的腿，按真实蚂蚁的走法：
  - 三脚步态：左前、右中、左后三条腿一起迈步，和另外三条轮流。
  - 脚尖落地后钉在地上不打滑，迈步时抬起划一道弧线，落到前方。
  - 步幅随速度变大，走路时节奏平稳，跑起来步子更快更大；每种蚂蚁的步幅按它自己的腿长限制。
  - 腿向两侧摊开，膝盖高过身体，身体压低。身体、头和触角仍由原来的动画驱动，节拍跟步态同步。
  - 更远的蚂蚁用原来的动画片段，节省性能。
- 检查动画：`-animcheck <文件夹>` 会让蚂蚁走、跑、绕圈，从侧面和正面逐帧存图；再加 `-markers` 会显示脚的落点。
- 想调整的话改 `game_config.json`：

```json
{ "npcs": { "countPerNest": 100, "minPerSpecies": 4, "chamberShare": 0.25, "meetRadius": 1.6 },
  "ant": { "proceduralLegs": true, "strideBase": 0.45, "stepHeight": 0.1, "legSpread": 1.15, "bodyDrop": 0.05 } }
```

## 地形和地面贴图

- 每种风格有自己的一套地面贴图（谷底、岸坡、高台各一张，加法线贴图），在 `Art/Ground/blue/` 和 `Art/Ground/amber/`。琥珀蚁穴不再是蓝色贴图换颜色，而是自己的龟裂黏土和红土。
- 谷底在镜头附近会叠一层更细的同款纹理，近看也清楚。
- 地形网格更细：高画质 0.35、中 0.5、低 0.8（每个格子的边长），起伏更自然。低画质会把所有贴图减半，省显存。
- 换地面贴图：把新图放进 `02_Concepts/Textures/`，按 `<风格>_<层>.png` 命名（例如 `amber_floor.png`），然后运行：

```bash
python3 ~/Desktop/AntGarden/Tools/make_ground_textures.py
```

  它会统一调色、做成无缝贴图、放大到 2048、生成法线贴图。之后在 Unity 里点 `AntGarden/Build Assets`。

## 遗迹小场景（巨人遗物、古蚁圣殿）

- 在地图（`M`）最下面一排点"遗迹 · 巨人遗物"或"遗迹 · 古蚁圣殿"进入。也可以用游戏参数 `-world "path-003@blue#relics"` 或 `-world "path-010@amber#temple"` 直接打开。
- 两个场景都是单个蚁穴，顶部封成隧道：顶在峡谷中间最高，到岸坡顶上落下来，和地面接在一起，下面挂着树根，有的根尖会发光。镜头不会穿到顶上去，飞蚁在隧道里不起飞。
- 巨人遗物：主隧道边上半埋着一只裂开的茶杯，另一侧的岸上堆着铜钱台地；生锈的钥匙沿着峡谷倒在一边；最大的洞室中间平铺着一颗纽扣，蚂蚁在上面走来走去。
- 古蚁圣殿：主隧道两岸是成对的陶土尖塔，塔之间是刻着蚁路纹样的尖拱门；路边有几簇六边形巢室；隧道尽头是一块发光的琥珀，里面封着一只远古飞蚁（游戏里的 Ant_003）。
- 素材：茶杯、钥匙、铜钱、纽扣、尖塔、拱门、巢室是 Tripo 生成的（正面图在 `02_Concepts/Fronts_for_3D/ruins/`）；琥珀神龛是代码生成的。摆放规则写在 `Scripts/Runtime/RuinScene.cs`。

## 对话：遗物、蚂蚁、记忆植物

- 走近遗物，屏幕上会提示"按 E 或用触角碰碰它"。碰一下，它会发光、响一声铃，在屏幕下方说一句话；再碰一下，接着说下一句。每种遗物有 2 到 4 句。
- 约 1/5 的 NPC 蚂蚁"带着话"：按 E 碰触角（或停下来按空格），它会说一句，下次再碰会换一句；其余的蚂蚁只碰触角，不说话。
- 约 7% 的发光植物是"记忆植物"：平时连闪两下、再停一会儿。触角碰亮它时，会显示一段访客留下的话。现在是 8 条预设的故事，等确定了"怎么留故事"再接上真正的留言。
- 所有台词写在 `Scripts/Runtime/Voices.cs`，中英各一份。铃声是程序生成的，每个说话的对象音高不同。

## 蚁群的路线（NPC 怎么走）

- NPC 蚂蚁按蚁群算法觅食。每个蚁穴最大的洞室是巢，路的尽头是食物点。路网上每段路、每个方向都记着两种信息素：
  - 出去找食物的蚂蚁，在路口按"往食物"信息素的浓度挑路，一路留下"往巢"的信息素；
  - 拿到食物的蚂蚁，按"往巢"信息素回家，一路留下"往食物"的信息素。
- 信息素会慢慢挥发，所以走得最多的几条路线会变成"蚂蚁大道"。游戏开局会先在后台预演一遍，打开时路线就已经成形。
- 两只蚂蚁迎面碰触角时，如果一只带着食物，另一只接下来 25 秒会更积极地沿食物路线走（招募）。
- NPC 转向比主角慢（每秒最多 3.2 弧度）；目标点被石头或墙挡住、或者已经走过，会直接换下一个点，不会绕着它转圈。
- 实测，400 只蚂蚁跑 40 秒：
  - 原地打转：每只每分钟从 1.37 次降到 0.09 次；
  - 突然掉头：从 1.61 次降到 0.27 次。
- 参数在 `GameConfig.cs` 的 `npcs.colony`：`alpha`（跟随信息素的程度）、`evaporation`（挥发快慢）、`explore`（无视信息素去探索的概率）、`turnRate`（转向速度）等。游戏参数 `-colony 0` 可以换回旧的走法，方便对比。

## 发光植物

- 每株发光植物的亮度都不一样：大约 30% 几乎不亮，10% 特别亮，其余在中间；每株的"呼吸"快慢和颜色也略有差别（色相差到 20°）。
- 2026-10-13 起"小灯珠"类植物整体调暗了一半左右，大多只是柔光，少数几株亮点。`plant_looks.json` 里的 `strength`：孢子柄 1.5、灯笼荚 1.8、小蘑菇 1.3、海葵菇 1.4、杯菇 1.3、层架菇 1.6；漂浮的孢子和隧道树根的发光根尖也调暗了。
- **用触角碰它**：蚂蚁爬行时触角向前探，触角尖碰到发光植物，它会在 0.25 秒内亮到平时的 4 倍左右，整株都泛光，周围地面也被照亮；保持 1 秒多后，用 3.5 秒慢慢暗回去。
- 光会传给附近 4 个单位以内的植物，像波纹一样一株接一株亮起来，亮度减半。
- 停下来按 `空格`，蚂蚁会主动伸出触角去点前面的植物。
- 参数在 `GameConfig.cs` 的 `glow`：`dormantShare`（几乎不亮的比例）、`brightShare`（特别亮的比例）、`hold` / `fade`（亮多久、暗多久）、`ripple`（传多远）、`lights`（同时借用几盏点光源照亮地面）。
- 扇形树的伞盖不再整片发荧光：只有亮的纹路发光，伞盖下沿和垂下的水滴最亮，顶部偏暗（`plant_looks.json` 里的 `lumMin` 和 `under`）。

## 植物精度

- 大型植物（夜光树干、扇形树、干枯巨菇、土塔蚁丘）用 4096 贴图（Tripo 原图就是 4096）；其余 2048。
- 植物在屏幕上占 20% 高度以下才换成简化模型（以前是 30%）。
- 想把别的植物也换成 4096：`Tools/plants_to_unity.sh 03_Models/Plants/<名字>_p1.glb --tex 4096`，再 `Build Assets`。

## 植物密度（2026-10-13）

- 峡谷两边的中小型植物大多加密了 20–40%：珊瑚菇、海葵菇、杯菇、果冻菇、卷须、层架菇、苔石、玻璃海绵、多肉、菌圃等。主世界的植物从约 5200 株增加到约 6600 株，高画质下仍是 60 帧（M3 Max）。
- 宽峡谷中间以前是空地，现在铺上不挡路的小石子、落叶和苔藓。琥珀蚁穴也有了落叶。
- 发光的孢子柄（小灯珠）反而少了一点，丛也小了一些（每丛 2–6 株）。
- 规则在 `GameConfig.cs` 的 `scatter.rules`：`spacing` 越小越密，`cluster` 是每丛几株。
- 新植物候选（Codex 正面图，等挑选后再用 Tripo 建模）：`02_Concepts/Plants_v12_候选/`，总览图是 `00_候选总览_v2.jpg`。

## 加入新的 Tripo 植物

1. 把正面图放进 `02_Concepts/Fronts_for_3D/`，然后用 Tripo 生成模型（脚本就在本机的 `Tools/` 里，不需要 T9）：

   ```bash
   ~/Desktop/AntGarden/Tools/tripo_batch.sh <名字1> <名字2>
   ```

   它把 `Fronts_for_3D/<名字>.png` 生成为 `03_Models/Plants/<名字>_p1.glb`，几个同时跑，每个约 2 分钟、约 60 点。已经有模型的会跳过，不会重复扣点。单个生成：`node Tools/tripo.mjs image <正面图> <输出.glb> --quality detailed`；查余额：`node Tools/tripo.mjs balance`。

   Tripo 的 API key 放在 `~/Desktop/AntGarden/.secrets.nosync/tripo_api_key.txt`，只粘 key 这一行，不要发到聊天里。这个文件夹是隐藏的（Finder 里按 `Command + Shift + .` 显示），名字带 `.nosync`，不会上传到 iCloud。
2. 运行 `Tools/plants_to_unity.sh` 转换成 Unity 格式（会自动生成近、中、远三档精度）。
3. 在 `UnityProject.nosync/Assets/AntGarden/Art/Plants/plant_looks.json` 里给它加一行外观设置：发光强度、发光的高度范围、只让贴图里亮的部分发光（`lumMin`）、摇摆幅度、粗糙度。
4. 在 Unity 里点 `AntGarden/Build Assets`，再在 `GameConfig.cs` 的 `scatter.rules` 里加一条摆放规则：
   - `dMin` / `dMax`：离峡谷边缘多远（负数在谷底，正数在岸上）；`spacing`：间距；`height`：高度范围。
   - `biomes = "amber"`：只长在琥珀风格的蚁穴里；不写就所有蚁穴都有。
   - 专门为某种风格画的植物，写进那个风格的 `nativePlants`，那里就不会再给它变色。
