# 3 · 改动影响表：改了什么，会牵动什么

动手之前先查这张表：你要改的东西在左边，中间是会跟着变的东西，右边是改完必须做的事。

三种"生效方式"：
- **改 json，不用打包**：在游戏的 `AntGarden_Data/StreamingAssets/game_config.json`（Mac 版在 `AntGarden.app/Contents/Resources/Data/StreamingAssets/`）里写要改的项，重开游戏就生效。只写要改的那几项。
- **要重新打包**：改了代码、着色器或素材，在 Unity 里用 `AntGarden → Build → Windows (x64)` / `macOS` 重新打包。
- **要先 Build Assets**：放进新模型、新贴图或改了 `plants.json` / `plant_looks.json`，先点 `AntGarden → Build Assets`，再打包。

## 内容和数据

| 你改了 | 会跟着变 | 改完要做 |
|---|---|---|
| 路径线稿（`04_Paths/Images/`） | 那个蚁穴的峡谷形状、洞室、拼接时转的角度、接缝位置、植物和蚂蚁的位置、遗迹物件和引路路线 | 重新识别 → 新 JSON 复制到 `StreamingAssets/Paths/` → 打包；看一遍地图和那个蚁穴 |
| 路径 JSON（`StreamingAssets/Paths/`） | 同上（不用重新识别） | 同上 |
| 世界组成 `defaultWorld` | 蜂巢有几格、谁挨着谁、哪里是遗迹；地图、接缝、蚂蚁总数、加载时间、帧率 | 打包；看加载时间和帧率（高画质应在 55–60 帧） |
| 蚁穴风格 `biomes`（颜色） | 那种风格的地面、植物、蚂蚁、雾、天空的颜色；**引路光点、接缝光粒的颜色也取自 `plantGlow`** | 改 json 即可 |
| 遗迹宽窄 `ruinWidth` | 遗迹的隧道宽度、洞室大小、物件离路多远、引路路线、隧道里的植物数量 | 改 json 即可；进遗迹走一遍，看物件有没有挡路 |
| 摆放规则 `scatter.rules` | 植物的种类、疏密、成簇程度；碰撞体（能不能穿过）；帧率 | 改 json 即可；看帧率 |
| 对话 `Voices.cs` | 遗物、蚂蚁、记忆植物说的话（中英各一份） | 打包 |

## 素材

| 你改了 | 会跟着变 | 改完要做 |
|---|---|---|
| 新植物模型（Tripo → `03_Models`） | 还不会出现在游戏里 | `Tools/plants_to_unity.sh` → `plant_looks.json` 加一行 → Build Assets → `scatter.rules` 加一条规则 → 打包 |
| 植物外观 `plant_looks.json` | 发光强度、摇摆、粗糙度 | Build Assets → 打包 |
| 地面贴图（`Art/Ground/`） | 所有同风格蚁穴的地面，**也包括接缝的斑块过渡**（它用邻居的地面） | 先出审核图 → Build Assets → 打包 |
| 蚂蚁模型或动画片段（`Art/Ants/`） | 步态测量（`ants.json`）、走路时腿的样子、碰触角的动作 | Build Assets → 打包 → 跑 `-legcheck` 看腿有没有抽搐 |
| 遗物模型（茶杯、钥匙……） | 遗迹里的物件、碰撞、能不能踩上去 | Build Assets → 打包；进遗迹看 |
| `.meta` 文件 | 删了或改了会让 Unity 找不到引用（材质丢失、粉色） | **不要动**；新文件的 `.meta` 要一起提交 |

## 代码

| 你改了 | 会跟着变 | 改完要做 |
|---|---|---|
| `Scripts/Core/`（`PathField`、`Stitcher`、`FieldStamper`……） | 所有峡谷的形状和拼接；和网页原型的一致性 | **必须**跑 `Tools/core_tests/run_tests.sh`，11 组全部通过；再打包看 |
| `TerrainBuilder.cs` | 地面网格、接缝过渡、加载时间 | 打包；看接缝、俯瞰图 |
| `Scatter.cs` | 植物摆放、碰撞、帧率 | 打包；看帧率 |
| `RuinScene.cs` / `TunnelRoof.cs` | 遗迹物件位置、隧道顶高度、引路路线的起点和终点 | 打包；用 `-sceneshots` 拍两处遗迹 |
| `GuideTrail.cs` / `SeamMotes.cs` | 引路光点 / 接缝光粒的分布 | 打包；用 `-trailfilm` 录一段看 |
| `AntController.cs` / `LegRig.cs` | 玩家蚂蚁的手感、贴地、腿 | 打包；`-legcheck`、自己用手柄试 |
| `CameraRig.cs` | 镜头跟随、穿墙、隧道里不穿顶 | 打包；`-camcheck` |
| `Atmosphere.cs` | 雾、环境光、隧道里的明暗、曝光 | 打包；对比改前改后的截图 |
| 着色器（`Shaders/`） | 画面外观；**`TerrainCore.cginc` 同时影响地面和接缝过渡** | 打包（Windows 版也要重新打） |
| `GameConfig.cs` 的默认值 | 不写 json 时的默认表现 | 打包；只想试数值时先用 json |

## 不要改

- Unity 版本：只能用 **2022.3.62f3c1**，换版本会改动整个工程。
- `ProjectSettings/`、`Assets/AntGarden/Generated/`（由 Build Assets 生成）。
- `01_References/Ants/` 里交付的设定。

## 检查工具（改完怎么证明没坏）

都是给打包好的程序加参数运行，结果是截图、视频或报告文件：

| 参数 | 检查什么 |
|---|---|
| `-sceneshots <文件夹>` | 每个区域拍游玩视角、蚂蚁视角、俯瞰图和地图；`-shotregions 4,5` 只拍指定的格子 |
| `-trailfilm <文件夹>` | 在两处遗迹沿引路路线走一遍（从隔壁蚁穴跨过接缝开始），逐帧保存，可以做成视频 |
| `-camcheck <文件夹>` | 镜头有没有抖、跳、穿墙 |
| `-legcheck <文件夹>` | 腿有没有抽搐 |
| `-padcheck <文件夹>` | 手柄每个键是否有效 |
| `Tools/core_tests/run_tests.sh` | 峡谷算法和网页原型是否逐位一致 |

改了玩家能看到的东西，要留一张截图在 `Docs/screenshots/` 作为证据。
