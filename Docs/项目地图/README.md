# 项目地图 · 先读这里

蚂蚁花园（Ant Garden）的全部内容分成四类来看。每一篇都写清楚：在哪个文件夹、用什么工具、谁能改、改了会牵动什么。

| | 这一篇讲什么 | 适合谁先读 |
|---|---|---|
| [1 · 从装置到资产与动画](1_从装置到资产与动画.md) | 蚂蚁在装置里挖出的通道，怎么一步步变成游戏里的峡谷、植物、蚂蚁和动画（流程、工具、每一步的产出在哪） | 所有人；做美术、做资产的同学 |
| [2 · 交互分类](2_交互分类.md) | 玩家能做的每一件事，按类别列出：移动与镜头、触角与交流、探索与引路、反馈、系统设置；还有 NPC 蚂蚁自己的行为 | 做交互、做叙事的同学 |
| [3 · 改动影响表](3_改动影响表.md) | 改了什么，会连带影响哪些东西，要重做哪几步，怎么检查 | 动手改东西之前一定要看 |
| [4 · 体验与产出](../../07_Outputs/README.md) | 怎么下载、打开、操作游戏；所有产出（游戏包、视频、截图、海报、报告）的清单和下载链接 | 想先玩一下的人；做汇报的人 |

其他说明：

- 每个文件夹装什么、能不能改：仓库根目录的 [README](../../README.md)。
- 详细的按键、参数、做法：[Unity 版操作说明](../Unity版_操作说明.md)。
- 最近一次大改动的记录：[报告](../报告/)。
