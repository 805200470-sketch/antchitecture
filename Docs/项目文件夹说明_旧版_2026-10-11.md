# 蚂蚁花园 Ant Garden · 项目总文件夹

看图、找模型、拿演示包，都在这里。从 2026-10-05 起，新东西只放这个文件夹，不再放 T9 硬盘。

| 文件夹 | 放什么 |
|---|---|
| `01_References` | 参考图。`Mood` 是氛围参考（夜晚的腐海），`Ants` 是每只蚂蚁的设定图（Ant_001–005），`Photos` 是真实蚂蚁和蚁穴照片 |
| `02_Concepts` | Codex 生成的图。`Codex_Archive` 收着 **Codex 生成过的全部原图**，包括没选用的稿子，按批次分文件夹，每批有 `00_总览.jpg` 和记录每张图提示词的 `prompts.md`。其余文件夹放选出来用的定稿：`Environment_v1` 第一版场景素材，`Sheets_v3` 正面 + 侧面设定图，`Fronts_for_3D` 给 Tripo 建模的正面图，`Textures` 地面贴图，`Prompts` 提示词 |
| `03_Models` | 3D 模型。`Ants` 是五只蚂蚁的 FBX、贴图、动画预览视频、渲染图和说明；`Ants_Source.nosync` 是蚂蚁的 Blender 源文件和建模流程（3 GB）；`Plants` 是 Tripo 生成的植物（GLB 原文件和预览图） |
| `04_Paths` | 蚁穴路径。`Images` 是 13 张原始路径图，`Networks` 是识别出的路径数据（JSON），`Path_Recognize_Package` 是路径识别工具 |
| `05_Builds.nosync` | 打包好的程序：`AntGarden_Windows.zip`（拷到 Windows 电脑解压，双击 AntGarden.exe）、`AntGarden_Mac/AntGarden.app`、`演示视频_高画质/`（投屏用的高画质视频） |
| `06_Prototypes` | 早期原型。`ant-garden-mvp_Codex_2026-09` 是 9 月 Codex 做的第一个网页 MVP（上传路径照片，生成六边形花园），运行方法见它自己的 `README.md`（要先运行 `npm install`），原件在 `文稿/DFPI毕设/ant-garden-mvp`。`Ant_Garden_Web_Demo` 是 10 月初的网页版 Demo（Three.js + 高斯泼溅），双击里面的 `Start.command` 打开，说明见 `Docs/网页原型_操作说明.md` |
| `UnityProject.nosync` | Unity 工程。在 Unity Hub 里点 Add（添加），选这个文件夹就能打开 |
| `Docs` | 文档和成果：`Unity版_操作说明.md`（按键、调参数、重新出图出视频的方法）、`演示视频/`（英文演示视频）、`PPT截图/`（4K 画面 + 英文界面截图，`00_总览.jpg` 是缩略总览）、`宣发海报/`（16:9 海报）、`最终汇报_2026-10-06/`（汇报 PPT 和讲稿）、`screenshots/`（开发过程中的测试截图） |
| `Tools` | 小工具：Tripo 建模（`tripo_batch.sh`）、Codex 出图（`codex_image.sh`）、Codex 原图归档（`archive_codex_images.py`）、Tripo 模型转 Unity（`plants_to_unity.sh`）、地面贴图（`make_ground_textures.py`）、视频、海报。全部列表见 `Docs/Unity版_操作说明.md` 最后一节 |

## 不同步 iCloud 的文件夹

名字带 `.nosync` 的文件夹只存在这台电脑上，不会同步到 iCloud：

- `UnityProject.nosync`：Unity 工程有上万个缓存文件，同步会拖慢电脑，还可能把工程弄坏。
- `05_Builds.nosync`、`03_Models/Ants_Source.nosync`：文件很大。
- `.secrets.nosync`（隐藏文件夹）：Tripo 的 API key，不能上传。
