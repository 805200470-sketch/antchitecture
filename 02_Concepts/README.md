# 02_Concepts · 概念图

大部分是 Codex（ChatGPT 的图像生成）画的，按用途分文件夹。每批图一般都有 `00_总览.jpg`。

| 子文件夹 | 内容 | 状态 |
|---|---|---|
| `Environment_v1/` | 第一版场景素材设定 | 历史 |
| `Sheets_v3/` | 植物的正面 + 侧面设定图 | 历史 |
| `Fronts_for_3D/` | **给 Tripo 建模用的正面图**（一种植物 / 道具一张）；`ruins/` 是遗迹道具 | 已建模的都在游戏里 |
| `Plants_v12_候选/` | 新植物候选，有一版 / 二版 / 三版，对照图是 `00_候选三版对照.jpg` | 🛠 **待挑选**，挑好后再建模 |
| `Ruins_v1/`、`Ruins_v2/`、`Ruins_v3/` | 遗迹的风格方向：v1 四个方向、v2 克制版、v3 隧道版（按游戏实景画） | v3 已做进游戏（巨人遗物、古蚁圣殿） |
| `Particle_Styles_v1/` | 现有三种风格（暖琥珀、古蚁圣殿、巨人遗物）按粒子蚁穴 v15 的画法重画的效果图，每种入口 / 中心两张；灯光色轮（12 段）的对应：`02_色轮对应_v2_一段一个场景.jpg`（现用，一段一个场景）、`01_色轮对应.jpg`（第一版），对应表 `mapping.md` | ✅ 已定：青 蓝色真菌林、橙 暖琥珀（已做成游戏场景）、红 古蚁圣殿、天蓝 巨人遗物 |
| `Textures/` | 地面贴图：`v7` 被否（太写实）、`v8` 细节太少、`v9`/`v10` 现用，每版有 `00_审核总览.jpg` | 现用 v9 / v10 |
| `Prompts/` | 提示词和批量任务表（`*_jobs.json`），给 `Tools/codex_batch.py` 用 | ✅ |
| `Codex_Archive/` | Codex 出过的全部原图（含没选用的），**不上传仓库**，只在主开发机上 | — |

**出图规则**：画风要成熟、克制，该有细节的地方有细节，其余大块概括，避免"AI 感"（满屏小光点、碎细节、霓虹色）。地面贴图先出审核图，确认后才进游戏。
