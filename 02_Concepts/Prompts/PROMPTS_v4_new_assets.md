# Ant Garden — 8 new assets, single images for Tripo (v4)

Each image becomes one 3D model in Tripo (image → model), so every image shows **one object, whole, alone**:
square 1024×1024, a three-quarter view from slightly above (about 20° down), the object centred and filling
about 80% of the height with clear margin on all sides, soft even studio light from the front-left, flat
light neutral grey background (#E8ECEC) edge to edge. Bold simple forms, restrained detail, soft gouache and
watercolour painted look — the same family as the existing fan tree, spore stalk and sponge mound. Glow
stays inside the outline (the game adds the light). No ground plane, cast shadow, text, labels or frame.

Save each as `~/Desktop/AntGarden/02_Concepts/Fronts_for_3D/<id>.png`.

Blue fungal forest (腐海·蓝): `bracket_shelf`, `coral_fungus`, `jelly_fungus`, `lantern_pods`.
Amber nest (琥珀·暖): `amber_resin`, `soil_spire`, `dry_mushroom`. Story prop for both: `seed_husk`.
