# 05_Builds.nosync · 打包好的游戏（不在仓库里）

这个文件夹只在主开发机上（约 2 GB），仓库里只有这份说明。

| 内容 | 说明 |
|---|---|
| `AntGarden_Windows/`、`AntGarden_Windows.zip` | Windows 版：解压后双击 `AntGarden.exe`；第一次打开如果弹出"Windows 已保护你的电脑"，点"更多信息 → 仍要运行" |
| `AntGarden_Mac/AntGarden.app` | Mac 版，开发测试用 |
| `演示视频_高画质/` | 投屏用的高画质演示视频 |

**自己打包**：在 Unity 里点菜单 **AntGarden → Build → Windows (x64)** 或 **macOS**，结果会输出到这里。要压缩包找负责人要网盘链接。
