# 03_Models · 3D 模型原文件（不在仓库里）

这个文件夹只在主开发机上，太大了（约 3.7 GB），仓库里只有这份说明。

| 子文件夹 | 内容 |
|---|---|
| `Ants/` | 五只蚂蚁的 FBX、贴图、动画预览、渲染图（约 330 MB） |
| `Ants_Source.nosync/` | 蚂蚁的 Blender 源文件和建模流程（约 3 GB）⛔ 交付的源文件，不要改 |
| `Plants/` | Tripo 生成的植物和遗迹道具（GLB 原文件 + 预览图，约 360 MB） |

**游戏里实际用的版本已经在仓库里**：`UnityProject.nosync/Assets/AntGarden/Art/`（植物带三档精度，蚂蚁带动画）。只有重新转换模型时才需要这里的原文件，找负责人要网盘链接。
