# Claude 开发交接：Path_Recognize

这是用户整体交互流程中的「输入蚁穴图片 → 提取路径网络」模块。请从这个已实现的模块继续开发，可以修改算法、页面、样式与接口。不要只根据预览重做静态页面。所有必要源码和示例都在本目录。

## 先运行，再接入

1. `node scripts/test.mjs`：算法及独立接口测试。
2. `node scripts/serve.mjs --open`：完整工作台。
3. 打开 `/examples/`：独立 Worker 调用 → 网络校验 → 下游邻接表构建。
4. 阅读 `docs/INTEGRATION.md`，以 `dist/path-recognize.mjs` 和 `dist/path-recognize.d.mts` 为独立调用入口。
5. 后续业务流程由用户继续提供。在下游回调处接入实际模块，保留可复核的输入图、ROI、参数、结果和推测标记。

无需安装 npm 依赖或构建。`dist/` 虽然沿用了部署目录名，但文件就是可直接编辑的原始 ESM/HTML/CSS。使用 HTTP 提供页面和 Worker；不要用 file:// 测试。

## 用户已确认的交互与算法取向

- 尽量用代码和传统图像处理，不依赖 AI 模型。
- 每条主要蚁道保留一条中心线，去掉碎分支；不是整幅图只取一条最长路线。
- 保留更换图片入口，换图后清理上张图的网络和编辑历史。
- 默认中心线叠加，不默认显示绿色区域填色与节点。
- 适度柔和转折，保留主路径和必要分叉，避免洞室内纹理造成的绕行。
- 断点连接需要图像证据，不能为了全图连通而穿过明显实心墙体。
- 手动擦除后，不要自动把用户剪断的位置重新连起来。
- 保留完整骨架、人工补画和擦除作为复核手段。
- 无需恢复已移除的「路径概览」板块。

## 源码地图

- `dist/app.js`：工作台状态、图片解码、ROI、参数、画布、手动编辑、历史、导出和 `window.Formic`。
- `dist/engine.mjs`：灰度、局部对比、分割、区域处理、骨架及像素图结构。
- `dist/surface-evidence.mjs`：浅色沟槽、多尺度形态学、两侧边缘与方向线索。
- `dist/reconstruction.mjs`：相对凹陷线索、缺口候选、图像代价路径、连接来源标记。
- `dist/main-paths.mjs`：主干筛选、短枝裁剪、链合并与图统计。
- `dist/center-routes.mjs`：已分割通道内部重寻中心路线，压制洞室内纹理绕行。
- `dist/path-smoothing.mjs`：掩膜约束平滑，保持节点和拓扑。
- `dist/network-export.mjs`：工作台和独立接口共享的 schema 2.5 JSON 转换。
- `dist/path-recognize.mjs`：无 DOM 的公共调用层，识别、手动掩膜更新和重新导出。
- `dist/worker.js`：原工作台后台线程；`dist/integration-worker.mjs`：独立接口后台线程。两者协议不同，不要互换。
- `examples/downstream.mjs`：真实的网络数据消费者：检查引用和几何端点、构建双向邻接表。

## 接口保持与修改

- 稳定交接对象是 `packet.network`，不是包含内部 TypedArray 的 `packet.analysis`。
- JSON `schemaVersion: "2.5"`，引擎 `engineVersion: "2.2.0"`；包版本是 `1.1.0`，三个版本含义不同。
- `network.nodes`、`network.edges[*].points`、`rawPoints` 使用原图像素坐标，左上角原点、Y 向下。
- `network.processing.roi`、算法掩膜、凹陷数组和算法参数里的像素距离使用处理分辨率；不要直接混用。
- `edges[*].source/target` 引用节点 ID；每次重新提取都可能重新编号。不要把这些 ID 当跨图片的持久主键。
- `inferredSegments[i]` 标记 `points[i] → points[i+1]` 这一段是否涉及推测连接。保留它，禁止无依据把推测升级为实测。
- 不含推测连接时，需要删除推测像素并重新计算拓扑；调用 `exportNetwork(..., {includeInference:false})`，不要只删除某些边。
- 任意断开的分量都可能是有效结果。下游应能接受零条边、多分量、闭环、自环以及一对节点之间的多条边。
- 新增字段优先兼容；更改坐标、字段含义或数据结构时应提升 schema、更新类型、示例和测试，并给出迁移说明。
- `quality.reviewRequired` 和相关 false 字段反映当前未进行物理连通验证与标注集精度评测，不要因测试通过就改成 true。

## 工作台状态规则

算法输入参数改变后标记 dirty，重新提取才生效；重新提取重置人工编辑。路径显示方式和柔和度改变只更新导出/显示。更换图片重置 ROI、结果、历史及主路径显示默认值，但现有部分算法滑块仍沿用工作台状态。手动修正历史最多 15 步。取消依赖终止 Worker 和任务 ID；图片解码也使用代次标记避免旧图覆盖新图。

默认值见 `DEFAULT_OPTIONS`。处理长边最大 1400 像素；工作台上传最大 25 MB / 6000 万像素。独立接口接收已解码 RGBA，不接收文件，调用方负责压缩、解码与文件大小检查。透明背景按白色合成。接口默认 ROI 为全图，工作台会自动建议 ROI；比较结果时需要传同一个 ROI。

## 已知边界与建议改进方向

单张图片提供的是外观线索，不足以恢复可靠的真实深度、遮挡层级和上下穿越。亮度、土壤纹理、洞室阴影均可能导致误分割。保留推测连接区分和人工校正，不使用手工描线冒充通用识别算法。可继续在有标注的多图样本上改进阈值、浅通道识别、断点筛选和剪枝，并单独报告连通率、误连接及漏检，而非只追求线条连在一起。
