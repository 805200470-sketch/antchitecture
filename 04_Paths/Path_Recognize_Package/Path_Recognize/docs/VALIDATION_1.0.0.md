## 交付包检查

`MANIFEST.sha256` 记录最终交付文件的 SHA-256；`node scripts/verify.mjs` 可核对是否与交付版一致。ZIP 包保留顶层 `Path_Recognize/` 目录和 macOS 启动脚本执行权限。

交付流程包括 ZIP CRC 检查、解压到另一包含空格的目录、再次运行全部测试与文件哈希检查，以及从解压目录启动 HTTP 服务并打开工作台和接入演示。用于确认代码没有依赖原电脑目录或原在线站点。
